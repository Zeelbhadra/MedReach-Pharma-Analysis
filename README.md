# MedReach Pharma — Field Force Analytics

## Project Overview
End-to-end data analysis project simulating a pharma consulting engagement 
for a fictional mid-size Indian pharmaceutical company.

## Business Problem
MedReach expanded its field force by 20% but saw no improvement in sales. 
This project identifies why and quantifies the opportunity cost.

## Tools Used
- PostgreSQL 18 — database design, data loading, advanced SQL queries
- Microsoft Excel — data audit, pivot table analysis
- Power BI Desktop — 4-page executive dashboard, DAX measures, star schema

## Key Findings
- 8x conversion rate gap between new (6%) and existing (46%) MRs
- MRs making equal calls to doctors with 12x prescription potential difference
- Central zone over-deployed with new hires despite existing strong coverage

## Quantified Impact
₹45 Lakhs annual revenue opportunity identified through targeting 
and onboarding optimisation — zero incremental headcount required
